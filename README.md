# Yet Another Translator

基于大语言模型的 BetterDiscord 翻译插件，支持自动翻译、单条翻译和发送前翻译。

## 功能介绍

- **自动翻译**：按版面独立开启，逐条翻译可见消息，随新消息和滚动跟进，复用已缓存的译文；侧栏图标标记已开启的版面。
- **快捷切换原文/译文**：消息悬浮工具条中的“文/A”图标可快速显示或隐藏本条译文，所有界面语言使用同一图标。
- **单条语言选择**：原文语言标签可点击，支持只修改这一条的翻译目标，或永久切换全局默认目标。
- **发送前翻译**：翻译草稿后再发送，保留回复和附件；可附带原文及目标语言的 AI 翻译标注。
- **图片文字翻译与概括**：右键图片翻译图中文字并概括要点，支持切换目标语言。
- **上下文与术语**：参考频道主题、附近消息、回复原文和自定义术语表。
- **消息显示**：保留 Markdown、自定义表情、提及和默认隐藏的剧透内容。
- **手动翻译器**：输入文字、选择目标语言并复制结果。
- **多语言界面**：跟随 Discord 语言，不支持的语言回退英文。

> **⚠️ 慎用：图片文字翻译与概括可能大量消耗 token。** 请按需使用，尤其留意大图、长图和重复重译。

## 使用方法

### 安装与配置 LLM

1. 从[发布页面](https://github.com/vempx/Yet-Another-Translator/releases)下载插件压缩包，解压得到 `YetAnotherTranslator.plugin.js`。
2. 在 BetterDiscord 设置中打开插件文件夹，放入文件并启用。升级时保留配置和术语表，替换旧插件，只保留一份插件文件。
3. 在“模型服务类型”中选择本地、在线或独立的 DeepSeek，填写 API 基础地址、模型 ID 和所需的 API Key。本地使用本机地址，支持服务根地址或 `/v1`；在线保留服务商给出的路径，如 `https://openrouter.ai/api/v1`，也可填写完整 `/chat/completions` 地址。在线接口须兼容 Chat Completions 并使用 HTTPS。
4. 可先点击“测试连接”，使用当前填写的配置测试而不保存。确认后点击弹窗底部“保存并关闭”；“取消”或直接关闭会丢弃本次编辑。上下文容量与最大输出长度按服务支持的范围设置。

**DeepSeek**：填写服务地址、模型 ID 和密钥。思考默认关闭，可开启并选择低／高／最大强度；思考与译文共用输出额度，只显示和发送最终译文。测试提示额度不足时，可降低思考强度或关闭思考后重试。

### 翻译消息

- 右键左侧版面或版面内消息，选择“开启此版面自动翻译”；设置页也可调整当前版面。按版面 ID 保存，频道和论坛帖子各自独立，不继承父论坛开关。已开启的版面名称后显示自动翻译图标；关闭只影响该版面，右键“查看原文”可查看原始内容。
- 右键消息可进行单条翻译或重新翻译。自动翻译关闭时，手动翻译保留原文。
- 设置中的默认目标语言在“保存并关闭”后应用。需要清除单条覆盖时，可先点击“应用默认语言并清除单条覆盖”，再保存。
- 点击原文语言标签，再点击语言名称，只重新翻译这一条；右侧环形箭头永久修改共享的默认目标并开启当前消息所属版面的自动翻译，其它版面的开关不变。设置在重启后保留。
- 升级时，旧全局开关若为开启，只迁移到当前可识别版面；其它版面不会自动开启。无法识别当前版面时保持关闭，可通过上述右键菜单开启。
- 设置中的“自动翻译时显示原文”默认关闭；开启后原文保留在译文上方。保存后更新已翻译消息的显示，无需重新调用模型。
- 右键打开手动翻译器，可翻译自行输入的文字。

本地模型、通用在线模型和 DeepSeek 分别记住服务地址、模型名称、API Key、超时和 token 容量；DeepSeek 思考选项也会保留。切换服务会恢复各自配置，点击“保存并关闭”后统一保存，取消会丢弃本次修改。已有配置按当前服务类型保留；从未保存的服务使用初始值，过去已覆盖的配置需重新填写一次。

插件注册名及配置文件统一使用 YetAnotherTranslator（YetAnotherTranslator.config.json）。升级时若新命名空间尚无设置，会读取旧配置一次；已有新设置不会被覆盖，原有术语路径保持有效。

默认开启“自动翻译时跳过自己的消息”，按当前登录账号 ID 判断。自己的消息保留原文，仍可作为其他消息的上下文及回复参考；手动翻译不受影响。可在设置中关闭此选项，保存后生效。

设置页按消息翻译、发送前翻译、模型服务、术语表、调试与工具分组；超时和 token 容量位于“模型服务 → 高级参数”。

### 图片文字翻译与概括

1. 选择本地 llama-server（需视觉模型及匹配的 mmproj），或选择 DeepSeek 并使用 `deepseek-flash`，填写对应 API 地址和密钥。
2. 右键消息中的图片，选择“翻译概括图片内文字”。结果显示在该图片下方，使用较小的灰色文字，原图保留。
3. 默认使用当前版面自动翻译所采用的共享默认目标语言。点击结果旁的 ENG／JPN 等原文语言标签可切换这张图片的目标语言，不修改全局设置。

通过所选服务的视觉 API 在一次生成中识别、翻译并概括图片文字，不使用额外 OCR。请求参考版面主题、图片说明、附近消息、回复及事先匹配的术语；仅出现在图片里的词条无法提前匹配。本地模式另有输入 token 计数检查，自动选模型时会查询模型列表；DeepSeek 直接生成，沿用思考设置并为单图保留 1024 个输入 token 的预算。切换目标语言复用图片数据，切回已完成语言或重新显示消息可直接恢复结果；再次右键翻译会读取最新上下文和术语并重译。只在手动操作时处理图片，通用在线模式暂不支持图片；DeepSeek 仅支持 `deepseek-flash` 及兼容的旧视觉别名。图片和参考上下文会发送至所配置的服务，DeepSeek 可能产生费用。

支持 Discord 图片附件及 Discord 代理的图片预览，单图最多 8 MB、单边最多 8192 像素、总计最多 16,777,216 像素；所有格式先检查尺寸，本地 WebP 转为 PNG，DeepSeek 直接接收原始 WebP。结果仅自己可见，停用插件或更改翻译配置后清空。更多限制与日志说明见 [图片翻译说明](docs/IMAGE_TRANSLATION.md)。

### 翻译后发送

发送前会跳过纯表情、纯网址、纯文件名及无文字图片／附件，原样发送，不查询术语或调用模型；双语发送模式下也不重复附加内容。网址或文件名前后包含中文等文字说明时仍正常翻译，无需手动添加空格。

1. 点击输入框旁带字母 A 的纸飞机图标，循环切换三种状态：不亮时发送原文，紫蓝色时仅发送译文，青绿色时发送原文及译文。悬停可查看当前发送模式。
2. 选择旁边的发送目标语言。它与收到消息的默认目标语言独立。
3. 输入内容后按 Enter 或点击发送，插件按当前模式提交消息。
4. 双语模式与设置中的“发送时附带原文”联动：按钮切换立即保存，设置编辑需“保存并关闭”。双语消息附带 AI 翻译标注，其小号灰字样式仅在本机显示。

### 使用术语表

1. 右键频道、论坛或帖子，选择“打开自定义翻译”。
2. 在插件设置的对应版区中填写术语表 JSON 文件的完整路径。
3. 点击“检查术语表”，通过后点击“保存并关闭”。帖子未单独配置时可继承父论坛配置。

可使用仓库提供的[术语表](glossaries/README.md)，或参考[生成提示词](GLOSSARY_GENERATION_PROMPT.md)制作自己的词表。文件修改后，新翻译会读取更新；已有译文可手动重新翻译。术语配置不会自动开启自动翻译。

可选“术语节省用量”默认关闭：减少独立短消息的附近术语，只保留命中别名、合并重复项并缩短备注；保留游戏与角色消歧信息。它可能减少辅助信息，需要时可关闭。缓存按实际发送的术语内容复用，修改未命中词条不会单独触发重新生成；修改已采用的词条或手动重新翻译仍会更新。

### Debug 日志

在设置中开启“Debug 日志”，填写本地绝对文件路径（例如 `C:/Logs/YetAnotherTranslator.log`），点击“保存并关闭”后复现问题。默认关闭；关闭后停止记录。

日志记录时间、模型、翻译类型、原文、完整提示词、响应、耗时、用量、缓存和错误，采用可阅读的 Markdown 与结构化 JSON。每份约 10 MB，保留 3 份轮转备份；写入失败不会中断翻译。不记录 API Key 或思考正文，但包含聊天与上下文，分享前请检查隐私内容。字段与事件见 [Debug 日志说明](docs/DEBUG_LOGGING.md)。

## 注意事项

- 收到消息的译文仅自己可见；发送翻译会将最终内容发给聊天对象。
- 消息和选中的上下文会发送到配置的模型服务；API Key 保存在本地配置中，未加密。在线翻译及连接测试可能产生费用，“查看请求用量”分别显示两者统计；取消请求不保证没有消耗。
- 翻译中修改草稿、回复、频道或发送选项会取消任务。失败、超长或格式不完整时保留草稿，不自动发送原文。纯附件直接发送，编辑已有消息不走发送翻译。
- 翻译质量取决于模型和可用上下文。连接测试通过后，建议用短文本确认效果；重要内容请核对原文。
